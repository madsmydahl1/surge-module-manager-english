# Contributing

This repository maintains Surge module management and Script-Hub platform integration for Scripting.

Follow these guidelines when submitting changes.

- Write modules, scripts, rule sets, and includes only to the user-authorized `iCloud Drive/Surge` directory.
- Keep accounts, cookies, tokens, private URLs, and unauthorized third-party content out of the code and documentation.
- Script-Hub handles format conversion. This repository handles the interface, import entry points, and local writes to Surge.
- If you change directory or import behavior, update the installation and setup instructions in the README.
